# 🐞 Catch The Insect

A fun and interactive browser game built using **HTML**, **CSS**, and **JavaScript**. Choose your favorite insect, catch as many as you can, and watch the challenge grow as more insects appear on the screen!

---

## 🚀 Features

* 🎮 Interactive gameplay with a simple and intuitive interface
* 🦟 Choose from multiple insects:

  * Fly
  * Mosquito
  * Spider
  * Roach
* ⏱️ Live timer to track your survival time
* 🏆 Real-time score counter
* 📈 Increasing difficulty as new insects continuously spawn
* ✨ Smooth animations and transitions

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## ▶️ Getting Started

1. Clone the repository

```bash
git clone https://github.com/Ahad-Alii/Catch-The-Insect.git
```

2. Open the project folder.

3. Double-click `index.html` or open it in your preferred web browser.

No additional setup or dependencies are required.

---

## 🎮 How to Play

1. Click **Play Game**.
2. Select your favorite insect.
3. Click on the insects as they appear.
4. Every insect you catch increases your score.
5. More insects will continue spawning, making the game increasingly difficult.
6. Try to achieve the highest score possible!
